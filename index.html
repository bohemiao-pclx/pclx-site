05 / 说明

下载前，先看一眼。

为什么第一次要手动安装？

0.5.1 还没有更新器。先手动安装 0.5.2，之后所有新版本都会在应用内提醒并一键更新。

需要安装 Java 吗？

不需要手动准备。安装版本或启动游戏时，PCL-X 会自动检测并下载匹配的 Java 运行时。

论坛和 Minecraft 账号通用吗？

不通用。论坛账户只用于发帖、好友与聊天，和微软 / 离线 Minecraft 账户相互独立。

遇到问题去哪里反馈？

可以进入应用内论坛的「求助」分类，或到 GitHub 更新仓库提交 Issue。
